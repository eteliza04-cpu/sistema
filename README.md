# 🏥 Sistema Básico para Botica

Sistema de gestión para boticas/farmacias - **SIN facturación electrónica** (solo boleta normal sin registro).  
Versión de prueba, fácil de usar.

## ✅ Funcionalidades
- Registro de productos (código, nombre, precio, stock)
- Registro de ventas con boleta simple
- Control de stock automático
- Búsqueda rápida de productos
- Reporte de ventas del día
- No requiere internet

## 🚀 Cómo usar
1. Descargar `sistema_botica.xlsm`
2. Habilitar macros en Excel
3. Registrar productos en la hoja "Productos"
4. Usar la hoja "Boleta" para vender
5. Ver reportes en "Reporte_Diario"

## 📌 Nota
- Este sistema es **para prueba** y NO emite facturas electrónicas.
- Para facturación oficial, consultar con SUNAT.
